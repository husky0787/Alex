# Persist attributed research before generating a research narrative

Researcher records source URLs and UTC capture times from successful browser navigation, requires a matching ingestion receipt, and returns the persisted research IDs. Ingestion and retrieval share one provenance validator and embedding adapter. Existing vectors without provenance are excluded rather than retroactively assigned invented sources; an operator must re-ingest them. The server records browser navigation time, not the article publication time, and does not certify the truth of the model's summary.

Reporter retrieves once before model execution and saves the full retrieved evidence alongside its generated report. If retrieval fails or yields no attributed results, it saves a deterministic holdings/price summary with an explicit unavailable reason and skips the research narrative. This deliberately favors traceability over generating a plausible general narrative that could imply nonexistent research. The fixed research sources are rendered independently of optional model tool calls and citations; retrieval relevance and narrative factuality still require live acceptance.

The shared embedding adapter mean-pools the single input's unpadded token vectors when the SageMaker feature-extraction pipeline returns them. This differs from the old first-token extraction; existing indexes must be re-embedded into a new index before switching to this adapter. The account inventory found no vector bucket in either configured region. Index text and serialized sources are non-filterable metadata because their size can exceed the filterable metadata limit.
