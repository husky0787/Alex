# Derive backfill progress from verified date coverage

The 90-day history window includes the current America/New_York calendar date and the preceding 89 dates. Classify each date as available, missing, weekend, holiday or not yet published; only published trading sessions count toward coverage. Use the latest source sighting per date, retaining immutable version IDs and provenance. History is a current projection of accepted observations, not a point-in-time report snapshot; task 5 owns report snapshots.

Restart backfill by recomputing missing sessions from persisted verified observations for each supported symbol, rather than advancing a single maximum-date cursor or adding another mutable batch watermark. Resume an overlapping interrupted run first; if it succeeds but covers only part of the requested range, fetch the remaining first-to-last missing dates through the same daily pipeline. A failed/partial resume is reported for the next operator pass, without an unbounded retry loop. New fetches can include covered dates between gaps; the existing version/sighting model prevents duplicate observations. Fully covered ranges are skipped, so detecting subsequent provider revisions requires explicit `ingest` of the desired range.

The CLI serializes all source calls with a shared 13-second minimum interval, including retries, to fit the documented Basic plan limit. This is process-local pacing, not a shared API-key quota coordinator; another process using the same key can still cause a bounded 429 failure. The batch reports each symbol's run/coverage and returns nonzero while any expected date is missing. Preserve explicit date arguments when continuing the same window on a later day; omitted dates intentionally follow the rolling window.

The UI fetches the frozen universe from the authenticated API. Chart lines break at missing/unpublished trading sessions, connect across scheduled non-trading days and never replace absent prices with zero. The table retains exact decimal OHLCV strings; floating-point conversion is limited to chart coordinates and formatted price labels. No new cloud resource or analysis snapshot behavior is introduced.
