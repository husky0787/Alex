## What to build

## Acceptance criteria

- [ ] 跑通登入、持倉、行情日期／歷史、分析報告、研究檢索的端到端案例。
- [ ] 收集真實資料流、壞資料隔離、缺漏回補、重跑防重複、告警送達及部署回滾的證據。
- [ ] 整理架構、啟動／重建／清理指南與短示範影片，區分課程原有功能和個人新增成果。
- [ ] 記錄實測時間、費用及限制，清楚標記尚未驗證項目，不將規劃當已部署。
- [ ] 確認展示環境與資料的保留方案；一個月是目標，提前完成仍遵守相同驗收標準。
